# Working in this repository

`ikigai-throttle` is an ikigai module: reliability interception overlays (RateLimit, Retry,
CircuitBreaker, Failover, Timeout, Throttle) and the state face that shows what they hold.
These rules are for every agent and every person working here. `CLAUDE.md` is a link to this
file.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text. Here that is the state face and every refusal an overlay answers.
- Security reports go through GitHub private vulnerability reporting, never a public issue.
- Every change lands through a pull request with green CI.
- Use American spelling in everything you write: code comments, docs, commit messages and pull
  requests.
